AUTOMATIZACIÓN DE APIS

1. Prerequisitos

- Sistema operativo Windows 11
- Java JDK versión 1.8 
- Maven versión 3.8.6
- IDE recomendado: Visual Studio Code o IntelliJ IDEA
- Conexión a Internet

Nota:
Se utiliza como dependencia Maven definida en el archivo pom.xml.


2. Comandos de instalación

Una vez clonado el repositorio ejecutar:
mvn clean install -DskipTests


4. Información adicional

- Se utilizó Karate DSL para pruebas de servicios REST.
- La API bajo prueba es pública: https://petstore.swagger.io/
